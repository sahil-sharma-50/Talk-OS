# About

## Build voice AI agents on AssemblyAI

Dates: September 1–30, 2026

Format: Online · month-long

Prize pool: $10,000

This is a month-long online challenge from lablab.ai and **AssemblyAI**. A month is long enough to build something that actually runs, and short enough to keep the momentum — you have the whole window to take an idea from an empty repo to a working voice agent.


Every project is built on AssemblyAI, the Voice AI infrastructure company for builders, whose speech-to-text, voice agent and speech understanding models sit behind products like Granola, HeyGen, Ashby and ClickUp. Additional information about builder access and the challenge will be shared as it becomes available.

Everyone is welcome to participate, regardless of previous AI or coding experience. Tutorials go live before the start, and mentors are in Discord throughout the build.

**You can join at any point.** Registration stays open for the entire build window, so it makes no difference whether you sign up on day one or halfway through. What matters is the submission deadline, and that one is the same for everyone.


# Challenge

## Build voice AI agents on AssemblyAI

Build a voice agent using AssemblyAI's real-time voice AI technology. Choose the approach that fits your idea and how much of the voice stack you want to build yourself.

Choose your path

#### Voice Agent API

Build an end-to-end voice agent through a single connection, with AssemblyAI handling the core voice interaction stack.

- Speech-to-text powered by Universal-3 Pro
- LLM routing and voice output
- Turn-taking and voice activity detection
- JSON-Schema tool calling
- Designed for fast, natural voice interactions

#### Realtime Speech-to-Text API

Use AssemblyAI's real-time speech-to-text API as the foundation of your voice agent, while bringing your own orchestration.

- Real-time speech-to-text over WebSocket
- Sub-second transcription
- Multilingual speech recognition
- Bring your own LLM and text-to-speech
- More control over your voice agent architecture
